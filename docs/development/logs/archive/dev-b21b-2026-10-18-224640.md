### Decisions
- Esc: clears the active parameter first; an Esc with nothing active still resets (the existing hotkey); dialogs keep their Esc (MUI swallows it).
- Follow MIDI default ON per session = the previous Auto Select default; Auto Select is hidden (nothing reads it).
- Wheel excluded inside dialogs / menus / popovers and while ANOTHER numeric field is focused (an explicit field focus wins); otherwise anywhere (user's choice).
- Shift: pitch axis -> selectedPitches, mode axis (Modes, Sound Channels row) -> selectedModes; no range -> the active slot only.
- One slot of Strings / Modes / Excitation -> the editor's Cell write (granular, Principle 2); a range, Mass and the matrices -> the Workbench vector write (Feedin / Feedback / SC editors write their matrix whole as before).
- Step lock read at pointerdown (live finding); hammer Pos % / Width mm fields are not step fields (scaled display units).
- Ruler flags: one map per pane id (localStorage) + a frozen copy per named layout (companion key like the workbench bindings).
- Read-only fields (tail, stiffness, damping) never become active; the mode-ruler workbench no longer hijacks selectedParameter.
