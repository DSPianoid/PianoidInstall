### ROOT CAUSE
- The "black summation" line = the SELECTED level's `sum-${selectedLevel}` series in gaussSeries.js (styled bold black via `isSel`: color=SUM_SELECTED_COLOR "black", width 5). Its ECharts legend NAME = the selected level's CAPTION (pianissimo..fortissimo, via `captionOf(k)`). So the summation IS one of the level legend entries → the "two functionalities mixed" (bug #2 clarity issue).
- Toggle DOESN'T STICK: GaussChart builds a NEW `chartOptions` object every render with `legend: { top:10, type:"scroll" }` (no `selected` key) and passes it to ReactECharts → setOption. Clicking the legend strip flips ECharts' INTERNAL ephemeral `legend.selected[caption]`; nothing in React owns/re-applies that toggle, so the next option rebuild (level change / param edit / any re-render — `values` gets a new ref → `perLevel`/`allSeries` recompute) lets the default (all-shown) win and the black line REAPPEARS. There is no React state for summation visibility.
